# PlayInClouds

PlayInClouds is an Airbnb-style marketplace for music rehearsal spaces and recording studios. It connects musicians and other guests who need temporary creative spaces with hosts who have suitable spaces available to rent.

## For guests

Guests can:

- Search for nearby spaces by city, date, time, group size, price, and distance.
- Explore results through listing cards and an interactive map.
- View photos, equipment, amenities, availability, host profiles, and reviews.
- Reserve spaces and pay securely through Stripe.
- Message hosts, receive notifications, and review completed bookings.

## For hosts

Space owners can:

- Create and manage rehearsal-space or recording-studio listings.
- Configure hourly availability, pricing, booking rules, and cancellation policies.
- Accept or reject reservation requests.
- Manage calendars, reservations, and guest conversations.
- Connect a Stripe account and receive payouts.

## Administration

Administrators can review and moderate listings before they become publicly available.

## Technology

The application is built with React 19, React Router, TypeScript, Tailwind CSS, Supabase/PostgreSQL, Supabase Edge Functions and Realtime, Stripe, Google Maps, Resend, and Cloudflare Turnstile.
